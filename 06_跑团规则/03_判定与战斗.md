# 判定与战斗

## 一、核心判定

**掷 d100，小于等于判定值即成功。**

```
判定值 = 40 + (属性 − 10) × 4 + 技能等级 × 8 + 情境修正
```

| 例 | 计算 | 判定值 |
|---|---|---|
| 沈砚用撬棍砸头（力量 12，格斗 0） | 40 + 8 + 0 − 25（打头） | 23 |
| 沈砚用撬棍砸头（格斗练到 2） | 40 + 8 + 16 − 25 | 39 |
| 苏晞记路（感知 13，观察 1） | 40 + 12 + 8 | 60 |
| 沈砚修发电机（感知 10，机械 2） | 40 + 0 + 16 | 56 |
| 沈砚说服老陈（意志…此处用感知+交涉） | 40 + 0 + 0 | 40（他不擅长） |

**上下限**：判定值最低 5，最高 95。掷出 01—05 永远成功（幸运），96—00 永远失败（意外）。

### 成功度（可选，但战斗里要用）

| 掷骰结果 | 成功度 |
|---|---|
| ≤ 判定值 − 30 | 大成功：+3 伤害 / 更快 / 更好 |
| ≤ 判定值 | 成功 |
| ≤ 判定值 + 15 | 失败但有代价（东西掉了、发出声音、多花时间） |
| > 判定值 + 15 | 失败 |

## 二、对抗判定

攻击方判定值 **减去** 防守方闪避值，再掷骰。

```
防守闪避 = (敏捷 − 10) × 3 + 情境修正
```

| 目标 | 闪避 |
|---|---|
| 普通人（敏捷 11） | 3 |
| 训练有素者（敏捷 14） | 12 |
| Z-1 / Z-4 / Z-5 / Z-6 | 0（不闪避） |
| Z-2 / Z-2b | 6 |
| Z-3（已扑出后） | 0 |

## 三、战斗流程

**一回合 ≈ 6 秒。每回合 2 个行动点。**

| 动作 | 消耗 | 说明 |
|---|---|---|
| 移动一个距离带 | 1 | 贴身↔近↔中↔远 |
| 近战攻击 | 1 | |
| 瞄准射击 | 1 瞄准 + 1 射击 | 不瞄准射击 -20 |
| 换弹 | 1 | 手枪/步枪；霰弹枪逐发装填 = 每发 1 点 |
| 起身 / 爬行 | 1 | |
| 推倒 / 顶住 | 1 | 力量对抗 |
| 说话（一句话） | 0 | 但不能是长句 |
| 掏东西 / 开锁 / 破门 | 1—2 | 视难度 |

**先手**：感知对抗（双方各掷，高者先）。被伏击时防守方第一回合不能行动。

### 距离带

| 带 | 距离 | 谁能打到 |
|---|---|---|
| 贴身 | 0—1.5m | 近战全部；枪械 -10 |
| 近 | 1.5—5m | 长柄、投掷、枪械；短刀打不到 |
| 中 | 5—25m | 枪械、弓弩；投掷 -20 |
| 远 | 25m+ | 枪械（-10/25m 递增） |

## 四、伤害

```
伤害 = 武器伤害 + 力量修正 + 成功度加成 − 目标护甲
力量修正 = (力量 − 10) ÷ 2（向下取整）
```

**部位**

| 部位 | 修正 | 效果 |
|---|---|---|
| 躯干 | 0 | 正常伤害 |
| 头部 | −25 | 伤害 ×2；对感染者见下 |
| 四肢 | −10 | 伤害 ×0.7；累积可致残 |
| 手/眼（极难） | −35 | 特殊效果（打掉武器、致盲） |

**感染者的"停止"判定**

| 类型 | 头部命中且最终伤害 ≥ | 结果 |
|---|---|---|
| Z-1 / Z-1b / Z-1c / Z-3 | 8 | 立即停止 |
| Z-2 / Z-2b / Z-4 / Z-6 | 10 | 立即停止 |
| Z-5 / Z-5b | 20 | 立即停止（普通刀斧达不到，需钝器重击/枪械/弩） |

未达阈值：造成伤害，但没停。躯干累计伤害 ≥ 结构值 → 倒地（丧失追击，仍会抓咬）。**打断颈椎**（力量对抗成功 + 钝器）：倒地且无法追击，但不结算 SP（未停止）。

|---|---|---|

| Z-4 | 30 | 抓 4 / 咬 8 |
| Z-5 | 45 | 抓 6 / 咬 12 |
| Z-6 | 20 | 抓 4 / 咬 9 |
| Z-1b | 40 | 咬 8 |

| Z-5b | 40 | 抓 5 / 咬 10 |

**命中后立刻做感染判定**（见第六节）。

## 六、感染判定（咬伤/抓伤后立即）

掷 d100，**小于等于感染率即感染**。

| 情形 | 基础感染率 | 可降低到 |
|---|---|---|
| 深咬（见血，>5mm） | 62 | 冲洗（10 分钟内）−15｜碘伏消毒 −10｜扩创 −10 → **最低 27** |
| 浅咬（破皮未出血） | 34 | 同上 → 最低 9 |
| 抓伤破皮 | 18 | 同上 → 最低 3 |
| 体液入眼/入口 | 12 | 只能大量清水冲洗 −5 |
| Z-4 破裂喷溅（有伤口） | 25 | 冲洗 −10 |
| 抗病毒血清（30 分钟内） | 固定 8 | 无法再降低 |

**重要**：这些修正**全部需要时间**。冲洗 5 分钟、消毒 2 分钟、扩创 10 分钟。在尸群中间做这些事，等于自杀。**这就是最残酷的取舍点。**

## 七、群体

| 规模 | 数量 | 规则 |
|---|---|---|
| 单个 | 1—2 | 正常战斗 |
| 群 | 3—8 | 每回合最多 2 只实际攻击（受通道限制），其余互相挤压；每回合玩家做一次敏捷判定，失败则被"围住"（无法后退，所有判定 −10） |
| 潮 | 9+ | 不能打。只能跑、堵门、上楼、上车。**GM 不许让玩家"清潮"。** |

**群的移动速度 = 最慢的那只。** 这是玩家唯一的结构性优势。

## 八、逃跑

掷敏捷对抗：

| 追击者 | 玩家需要 |
|---|---|
| Z-1 / Z-4 / Z-5 / Z-6 | 自动成功（除非被围、负重 >80%、或腿伤） |
| Z-2 / Z-2b | 判定值 −10；失败则被扑倒一次 |
| 人（成年男性） | 正常对抗；对方有枪则另算 |

**逃跑会掉东西**：每逃一次，掷 d100，≤25 掉一件（GM 选最合理的：手电、水壶、一只鞋）。

## 九、其他常见判定（速查）

| 行为 | 属性 + 技能 | 难度修正 |
|---|---|---|
| 撬门 | 力量 + 机械 | 木门 0 / 防盗门 −25 / 有撬棍 +15 |
| 静音开门 | 敏捷 + 潜行 | 老门 −10 / 上油 +10 |
| 潜行穿过走廊 | 敏捷 + 潜行 | 有碎玻璃 −20 / 黑暗 +10（对丧尸而言黑暗无用，它们靠听） |
| 听声辨位 | 感知 + 观察 | 隔一层楼 −15 |
| 搜刮快速翻找 | 感知 + 观察 | 每 10 分钟一次 |
| 急救止血 | 感知 + 医疗 | 大出血 −15 / 有急救包 +10 |
| 说服 | 感知 + 交涉 | 对方有戒心 −15 / 有他想要的东西 +20 |
| 识破谎言 | 感知 + 观察 | 对方是老手 −20 |
| 修发动机 | 感知 + 机械 | 缺零件 −25 |
| 开车脱困 | 敏捷 + 驾驶 | 路上有尸群 −20 |
| 扛人跑 | 力量 + 体质 | 每 100 米一次判定，失败则体力 −1 |

## 十、倒下与死亡

生命值 ≤ 0 → **倒下**，不是立刻死。

- 倒下后 1—3 轮内意识清醒：能说话、能做一个动作（递东西、按按钮、扣扳机）。
- 每轮掷 d100 ≤ 体质 × 3 则稳定，否则失去 1 点生命并继续流血。
- 无人处理且持续失血 → 3 轮后死亡。
- 死亡后 3—30 分钟，若脑部完好且体内有病毒 → 复苏。

**这一条要真的用。** 倒下那 1—3 轮，往往是整个跑团最有分量的三句话。
