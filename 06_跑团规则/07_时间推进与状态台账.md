# 时间推进与状态台账

## 一、时间单位

| 单位 | 用途 |
|---|---|
| 轮（6 秒） | 战斗 |
| 分钟 | 搜刮、包扎、对话 |
| 小时 | 赶路、休息、放哨 |
| 半天 | 一次外出行动 |
| 天 | 消耗结算（食物、水、疲劳、伤口） |

**默认时间流速**：一轮对话 = 3—10 分钟；一次搜刮 = 20—60 分钟；一次穿城 = 2—4 小时。

## 二、每天的时间结构（11 月）

| 时段 | 时间 | 能做什么 |
|---|---|---|
| 夜 | 17:30—05:30 | 只能待在有门的地方；放哨；修理；说话 |
| 拂晓 | 05:30—06:50 | 潜行移动最佳窗口 |
| 上午 | 06:50—11:00 | 主力行动时段 |
| 正午 | 11:00—14:00 | 最安全（温度最高、光最好） |
| 下午 | 14:00—16:30 | 行动，但必须在 16:00 前决定在哪过夜 |
| 黄昏 | 16:30—17:30 | 最危险，不要在街上 |

## 三、状态什么时候报

**默认不报。** 日常对话、做饭、分配东西——不报数字。

**只在三种情况下报（每次只报变化的那几项，一两行）：**

1. **数值跨级**（口渴 1→2、疲劳 2→3、伤口从"红"变"化脓"）。
2. **物资有明显变化**（水剩 1 瓶、弹药剩 3 发、SP 到账）。
3. **玩家主动问**（"我还剩多少水？"）。

格式（简短，不用表格）：

```
—— 11/14 09:20 · 口渴 2 · 疲劳 2 · 水剩 1 瓶 · 左手掌划伤（已包扎）
```

**禁止**：每轮末尾贴完整状态表、贴属性条、贴经验条。

## 五、日结清单（每过一天做一次，60 秒）

1. 食物 −1 天份（两人）；水 −4L。
2. 饥饿 +1（若不足 800 千卡/人）、口渴 +1（若不足 2L/人）。
3. 疲劳：睡够 → 归 0；没睡好 → 保留。
4. 伤口：按时间推进感染阶段。
5. 体温：按天气与衣物。
6. SP / EXP：只在有结算时变化。
7. 世界：势力在做什么（按 `03_角色/05_人物关系网与登场表.md`）。
8. 写一句"今天发生了什么"进存档。

## 六、跳天规则

玩家说"睡到天亮""等到天黑""过两天"时：

1. **先问条件**：有地方睡吗？有人守吗？有吃的吗？（不是问玩家，是 GM 自己判断）
2. **掷一次事件**（d100，≤25 有夜间事件：敲门、玻璃碎、远处枪声、狗叫、发烧）。
3. **结算消耗**（日结清单）。
4. **给一段"醒来"的画面**（不是总结）。
5. 不要一次跳超过 3 天；超过就拆成几次，中间要有戏。

## 七、长期推进（每 30 天）

| 项目 | 变化 |
|---|---|
| 季节 | 推进一档（见 `01_世界观/04`） |
| 感染者 | 全局活跃数 ×0.93^周数 |
| 势力 | 至少一个势力发生结构性变化（换了头、搬了家、被灭了、合并了） |
| NPC | 至少一个 NPC 死、走、或者变 |
| 苏晞 | 一项技能 +1（需合理剧情），或者一次态度转折 |
| 系统 | 等级上限不变，但可解锁更高阶条目（按等级） |
