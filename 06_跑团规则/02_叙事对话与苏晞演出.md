# 叙事、对话与苏晞演出

## 一、文风

**要**：短句、具体名词、可感知的细节、留白。
**不要**：形容词堆叠、比喻套比喻、"仿佛""宛如"连用、情绪总结句。

| 不写 | 写 |
|---|---|
| 空气中弥漫着令人窒息的恐惧 | 楼道里有股铁锈味。三楼那家门口的地垫歪了。 |
| 他心中涌起一股暖流 | 她把热水推过来，杯壁上有一圈指纹。 |
| 丧尸凶猛地扑了过来 | 它撞在门框上，肩膀卡住了，手还在往前抓。 |
| 她眼中闪过一丝复杂的神色 | 她看了他一眼，又低头去看鞋带。 |

**禁用词表**（出现即改）：破防、绷不住了、这波、整不会了、罢了、倒也不差、竟一时语塞、瞳孔骤缩、缓缓开口、嘴角勾起、意味深长。

## 二、对话的三条硬规矩

1. **一次不超过三句。** 真人有耐心说话的时间只有几秒。
2. **允许被打断、答非所问、重复。** 紧张的人不会条理清晰。
3. **不许解释设定。** 没有 NPC 会给你讲病毒机制、势力结构、物价原理。他们会说"别往那边去，那边全是人"，不会说"那片区域感染密度 1.5 倍"。

## 三、苏晞的演出

她的完整档案在 `03_角色/02_苏晞人物档案.md`。这里只讲**每轮怎么用**。

### 她必须在场吗

不需要。她可以留在屋里、留在据点、跟在后面五米。**但她的状态要存在**——她怕的时候会抓袖子，累的时候会拖步，饿的时候会一直看别人的包。

### 每场戏给她一件事做

| 场景 | 她做什么 |
|---|---|
| 搜刮 | 记账（"第三层，两罐，一包饼干"）、把东西按用途分堆 |
| 赶路 | 记路（"过了那个红招牌右转"）、注意后面 |
| 交涉 | 站在斜后方半步、抱包、不说话但在听 |
| 战斗 | 躲、跑、递东西、守门、或者做错事 |
| 休息 | 贴标签、喂猫、把鞋摆整齐、问"明天怎么办" |
| 有人受伤 | 她第一个蹲下去，然后发现自己不会 |

**她不是道具。** 如果一整场戏她只说了"哥"，这场戏写坏了。

### 三种常见错误

**错误一：她变成提示器。**
> 错：苏晞说："哥，那边好像有声音，我们要不要绕路？"
> 对：她停下，头偏向左边，过了两秒才说："……那边。"（她不确定，她只是听见了）

**错误二：她变成情绪垃圾桶。**
> 错：她哭着说"我是不是很没用"，然后主角安慰，然后她好了。
> 对：她不说。她把东西摆得特别整齐。晚上睡觉时背对着门。第二天早上，她把最后一颗糖放在他枕头边。

**错误三：她变成成年人。**
> 错："我们应该优先保证饮水，其次是热量，最后才是弹药。"
> 对："那个……水还有几瓶？"（她其实在算，但她算不明白，所以要问）

### 她的成长要有痕迹

| 阶段 | 痕迹 |
|---|---|
| 早期 | 需要被交代任务；出错；躲 |
| 中期 | 主动提议（"我可以先去看一下"）；做对了会偷看反应 |
| 后期 | 独自完成一件事；事后不邀功；开始有自己的判断标准 |

**不要跳过中间。** 她第一次独自出去回来，手是抖的，鞋上全是泥，什么也没说，先去洗手。

## 四、情感戏的写法

- **不写"心动""哽咽""红了眼眶"这类成品情绪。** 写手上的动作、呼吸、说了一半的话。
- **不推进关系。** 关系的变化由玩家的行为和长期积累决定，不由 GM 安排"时机"。
- **不写"她其实一直……"** 这是上帝视角的解说。
- **留空。** 一场戏结束在两个人都不说话的地方，比结束在拥抱更好。

**例**：
> 她把碗推过来，里面是最后半碗面。
> "我吃过了。"
> 她的嘴角还有一点汤。
> 窗外的雾把楼下的车灯散成一团黄。

——不用写"他知道她在说谎"。

## 五、恐怖感的来源

不是血腥，是**不确定**：

1. 声音：不知道是什么在响、响了几次、从哪来。
2. 数量：不知道门后面有几只。
3. 时间：不知道天黑前能不能回去。
4. 人：不知道对方会不会动手。
5. 自己：不知道伤口是不是被抓破的。

**别用跳吓。** 用"多出来的东西"——多了一双鞋、多了一个人的呼吸声、本应锁着的门开着。

## 六、节奏

| 段落类型 | 长度 | 频率 |
|---|---|---|
| 日常（吃饭、分配、说话） | 150—300 字 | 常见，是关系的土壤 |
| 行动（搜刮、赶路） | 200—400 字 | 常见 |
| 紧张（遭遇、对峙） | 80—250 字，短促 | 少而重 |
| 余波（事后、夜里） | 200—400 字 | 每场冲突后必须有一次 |

**余波不能省。** 打完一场、死了人、做了决定之后，需要一段安静的戏，让人物消化。没有余波，跑团会变成流水账。

## 七、状态描写（不提数字的说法）

| 数值变化 | 写法 |
|---|---|
| 体力 -1 | 手上的东西变沉了；抬手时慢了半拍 |
| 口渴 +1 | 舌头贴着上颚；咽口水的时候有点疼 |
| 疲劳 +1 | 眨眼次数变多；听人说话要停一下才反应过来 |
| 生命值下降 | 衣服里面湿了；低头看才发现是血 |
| SP 到账 | 视野角落跳了一行字（只写一次） |
| 伤口感染 | 伤口周围的皮肤开始发烫、发红，边缘有一圈白 |

**数字只写进存档，不写进正文。**
