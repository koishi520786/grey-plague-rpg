# 感染机制与生理

## 一、病毒做了什么

GX-9 只做三件事：

1. **占据运动中枢**（基底节、脑干运动核）。它不产生思想，只产生"向活体移动并咬"的输出。
2. **关闭痛觉与疲劳抑制**。所以它们能一直走，走到肌肉撕裂、走到关节脱臼。这既是它们的可怕之处，也是它们崩溃的原因。
3. **关闭抑制性神经通路**。攻击没有预兆，没有犹豫，没有"先看看"。

**它没有做的事**：它不增加肌肉量，不改变骨密度，不产生新器官，不产生电、酸、黏液或任何超自然能力。所有看起来"变异"的形态，都是损伤、脱水、腐败或环境浸泡的结果。

## 二、感官是剩下的全部

| 感官 | 状态 | 实际效果 |
|---|---|---|
| 视觉 | 严重退化，只能感知 3—5 米内的移动轮廓 | 静止不动 = 隐形（前提是它没闻到/听到你） |
| 听觉 | 保留，甚至因失去其他输入而更敏感 | 60 米内普通说话可辨；枪声 800 米以上 |
| 嗅觉 | 保留，对血、汗、香水、烟味敏感 | 顺风 200 米可察觉血 |
| 触觉 | 迟钝但存在 | 被碰会转向，被绊会倒 |
| 痛觉 | 无 | 打到它不会退，只会继续 |

**听觉是主要矛盾。** 一切战术都建立在"谁的声音更大"上。

## 三、能量与"用完"

感染者不进食（咬人不吞咽），靠自身储备活动：

| 消耗来源 | 影响 |
|---|---|
| 糖原 | 感染后 8—20 小时耗尽，之后靠肌肉蛋白 |
| 肌肉蛋白 | 每天约 1.2—2% 的肌肉被分解，直到无法支撑站立 |
| 体液 | 无补充，血液浓缩，关节液干涸 → 僵硬 |

由此得出可用的推算：**一个区域的感染者，活跃期约 3 周，之后逐周衰减 6—9%，第 9 周后大多进入"静默"。** 这不是后台刷新数据，是可以被 NPC 观察到的现象——老练的幸存者会知道"这栋楼的已经软了，那栋楼的还硬"。

## 四、击败一个感染者

**只有破坏脑干（含延髓）和大脑皮层能使其永久停止。**

| 方式 | 结果 |
|---|---|
| 打断颈椎（Z-1 有效） | 头部失去控制，扑倒，仍在咬空气；能爬 20—40 分钟，之后因无法进食而彻底僵死（不等于停止） |
| 破坏躯干（累计伤害达上限） | 倒地，失去追击能力，仍会抓、会咬靠近的东西 |
| 断肢 | 失去该肢体功能；断腿则爬行 |
| 头部贯穿 | 立刻停止 |
| 火 | 组织收缩导致倒地，但燃烧的个体仍可能移动 1—3 分钟；火会引来更多 |
| 电 | 短暂痉挛失控；不致命（除非高压） |
| 窒息/溺水 | 无效（不需氧） |
| 高空坠落 | 骨骼碎裂，匍匐或静止 |

**这条设定决定战斗的手感：打身体是拖延，打头是解决，而打头需要距离、稳定和穿透力。**

## 五、被咬之后

| 情形 | 处理窗口 | 结果 |
|---|---|---|
| 深咬（见血、伤口 >5mm） | 立刻冲洗 + 消毒 + 尽量扩创 | 感染率从 62% 降到约 40%，不能归零 |
| 浅咬（未出血） | 立刻冲洗消毒 | 降到 15% 以下 |
| 抓伤破皮 | 冲洗消毒 | 降到 10% 以下 |
| 眼睛/口腔溅入 | 大量清水冲洗 | 无有效手段 |
| 注射抗病毒血清（MED-014） | 咬伤后 30 分钟内 | 感染率降到 8% 以下，需 1200 SP、等级 8，且完成过里程碑 MS-06 |

**没有疫苗，没有治愈。** 一期到三期之间只有 2—8 小时，且前 1 小时几乎没有症状。

## 六、死亡与"回来"

- 被感染者杀死的人，如果脑部完好，死后 3—30 分钟内会自行进入复苏期。
- 因其他原因死亡（失血、坠楼、疾病）的人，**不会**变成感染者——除非体内已有病毒。
- 脑部被破坏的尸体不会再动。这是唯一可靠的处理方式，也是所有据点处理死者的规矩。

## 七、写场景时的三条纪律

1. **给感官细节，不给数据。** 写"它的下巴脱了，一动就有声音"，不写"HP 20/20"。
2. **让它们笨。** 卡在楼梯转角、被自己的脚绊住、跟着声音撞门。蠢是设定，不是 GM 放水。
3. **不让它们变聪明。** 没有"学会了绕后"的丧尸。只有环境造成的意外巧合（比如被堵住的走廊），且必须能解释。
