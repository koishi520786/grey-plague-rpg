## 一句话设定

2026 年 11 月 13 日，临江市陷落第七天。18 岁的**沈砚**和 16 岁的**苏晞**从断电的出租屋里睁眼——他身上多了一个只有他能看见的结算系统：击杀一只普通感染者，账户里跳进 10 SP。

## 三个核心承诺

1. **玩家只控制一个人。** 沈砚的一切言行由玩家写，没写出来的心思、台词、动作就是没有发生。
2. **世界不围着主角转。** 8 个势力、26 名 NPC 各有自己的账本，主角不在场时他们也照常做事。
3. **代价是真的。** 子弹要钱，伤口要养，感染会致死；刷丧尸会被系统扣系数，而不是越刷越强。

## 给 AI 的读法（三步）

1. 读 `AI_START_HERE.md` → 确定任务类型与读序。
2. 进对应目录先读 `00_` 开头的索引，再按编号打开正文；索引摘要不是正文。
3. 只有需要判定/买卖/加点时才打开 `06_跑团规则/`、`交易系统/`、`系统设定/`，不要一次加载全库。

## 一致性约束（改内容前必读）

- **价格只有一个权威**：`交易系统/商品索引.md`；规则与限购在 `交易系统/末日生存交易手册.md`。
- **成长数值只有一个权威**：`系统设定/经验与等级.md`、`系统设定/属性与技能.md`。
- 改价必须同时改索引与手册的价格带，并跑校验：

```bash
python tools/check.py
```

校验会检查：编号唯一、价格落在品类价格带内、跨类重登同价、交叉引用有效、计数与 `08_索引/COUNTS.md` 对应。

## 本地构建网站

```bash
pip install "markdown>=3.5,<4"
python tools/build_site.py --src . --out site --repo koishi520786/grey-plague-rpg
# 打开 site/index.html，或 python -m http.server -d site 8000
```

推送到 `main` 后，GitHub Actions 会自动重新构建并发布；站点正文与仓库 Markdown 同源，不存在第二份内容。

## 设计原则

**规则可以少，设定不能空。** 少写禁令，多写物价、路线、人的脾气。禁令堆多了 AI 会变呆；设定写空了 AI 会开始编。
