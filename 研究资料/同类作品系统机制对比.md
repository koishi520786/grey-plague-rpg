## 一、《末日求生：我有系统商城》（作者：寒渡鸦，纵横中文网，连载中）

**证据等级：原文**（第 1 章《系统商城》正文片段，纵横书籍页 2026-11-15 可读）

### 可确认的原文事实

| 项目 | 原文信息 |
|---|---|
| 丧尸分级 | 有"阶 + 级"两级记号，出现的是「一阶一级丧尸」 |
| 击杀奖励 | 【击杀一阶一级丧尸，获得 1.00 系统币】——基准怪 = **1.00 系统币**，带两位小数 |
| 奖励随等级 | 系统自述：「击杀丧尸按等级折算系统币。一阶一级丧尸基准掉落 1.00 系统币，等级越高，掉落越多。宿主升级系统后，折算率同步提升。」 |
| 商城规模 | 「商城全品类开放。价格随等级、品质浮动。」——**开局即全品类**，不做品类锁 |
| 食物价格 | 压缩饼干（1 份）= **1.00 系统币**（与一只基准丧尸等值） |
| 饮水价格 | 干净水 1 瓶 = **15 系统币** |
| 药品价格 | 消炎药 1 盒 = **80 系统币** |
| 武器价格 | 「一把像样的短刀」= **300 系统币**；主角自评"100 币在这儿，跟揣着十块钱逛商场差不多" |
| 升级而非重买 | 杀猪刀（残破）→ 完好 = **50.00 系统币**；「买把新的完好的要一百多，升级只要 50」；下一档 = 100 |
| 新手礼包 | 【检测到宿主处于危险环境，自动发放新手求生大礼包】= 100 系统币 + 破旧小屋 + 滑板车 + 杀猪刀（残破·卷刃·带豁口） |
| 系统位阶 | 世界设定里"系统"是人人皆有的低配玩意（只能对个话、递个东西），主角这个是**升级版** |
| 生存压力手段 | 水 15 币/瓶，而基准怪只给 1 币 → 早期喝水就是奢侈品；新手礼包给的是"残破"装备，要花币修 |

### 可提炼的结构

1. **单价锚定最便宜的食物**：1 币 = 一份压缩饼干。这条锚让玩家天然理解"一只怪 = 一顿"。
2. **饮水刻意贵 15 倍**：把最刚需的东西定成奢侈品，逼玩家去现实世界找水。
3. **升级价 < 新买价的一半**：鼓励"养成手里的东西"，而不是不断换代。
4. **开局面板不小气，但给的都是残次品**：礼包给的是"能用的破东西"，不是优势。
5. **折算率随系统升级提升**：等于承认"后期打同样一只怪更值钱"，是防早期卡死的补偿机制。

## 二、《末日逃出生天》（作者：阿兴的幻想，小说阅读网，连载）

**证据等级：原文**（第 1 章系统说明段落，readnovel 书籍页片段）
**另有【二手】**：红袖/网文百科的问答式综述页（AI 生成痕迹明显，数字仅作参照）

### 可确认的原文事实

| 项目 | 原文信息 |
|---|---|
| 系统定位 | 系统自述：「本系统只是个辅助系统，只能为宿主提供辅助要求」；「系统并不是你看的小说那样的全能且无敌」 |
| 属性面板 | 四项：**精神 / 体质 / 力量 / 速度**，各「满级 10」，普通人平均 5—6 |
| 商城分类 | 「商城总共分为了四大类分别为：**医疗，防具，武器和载具**」 |
| **没有食物与水** | 主角发现商城里没有食物和水，反问系统，此处为作品的核心压力设计 |
| 签到积分 | 活着一天签到 **10** 分；周签到 **20** 分；月签到 **60** 分 |
| 击杀奖励 | **一个普通丧尸 1 积分**（原文："一个普通丧尸1积分,二级和三级丧尸并没有详细说明"） |
| 医疗价 | 棉签 **1** 分；碘伏 **5** 分 |
| 武器价 | 军用匕首 **10** 分；手枪 **30** 分 |
| 弹药价 | 子弹「统一 **2 积分**一颗」 |
| 载具价 | 最便宜的崭新桑塔纳 **70** 分 |
| 属性价 | 身体点数「一点 **100 积分**」 |

### 【二手】补充（未核正文，仅记录）

- 进化丧尸按阶段给分，最高 50 分。
- 丧尸有"手→脚→躯干→头部"依次异变的进化路径，动物感染后成为丧尸兽。

### 可提炼的结构

1. **极端克制型经济**：一把手枪 = 30 只怪，一点属性 = 100 只怪。成长极慢，靠签到的固定收入兜底。
2. **签到是"活着"的报酬**：不击杀也有收入，但少到只能维持"不饿死"的错觉——因为它根本不卖吃的。
3. **品类锁在"非食物"上**：商城卖的是"让你能打、能跑、能护住自己"的东西，吃饭喝水必须出门。这是最值得抄的思路。
4. **属性上限 10、普通人 5—6**：小数值区间，避免后期数值膨胀。
5. **弹药单价比武器更"疼"**：2 分/发 ≈ 2 只怪，一梭子就是一个街区。

## 三、《全球恐慌：尸灾纪元》（红袖添香 / 阅文系，连载）

**证据等级：二手**（多个平台的百科式综述页，含大量结构化描述与"逐字还原系统语音"式表述，但**未读到正文**）
**结论：只取结构，不取数字。**

### 【二手】记录到的机制描述

| 项目 | 二手描述 |
|---|---|
| 系统模块 | 四大固定模块：**商城 / 丧尸图鉴 / 个人资料 / 个人技能** |
| 图鉴 | 免费自动鉴定，遇新型感染者触发弹窗：体型、攻击模式、弱点、注意事项 |
| 分层解锁 | 第 2 章"仅开放一层货架"（基础食物 + 冷兵器）；第 9 章后解锁二级 |
| 积分 | 「积分仅来自击杀（丧尸 2 分、暴走丧尸 5 分、喷吐者 5 分）」 |
| 技能树 | 需前置条件，如「蛇皮走位」需 敏捷 ≥6 且消耗 2 点技能点 |
| 制作 | 「装备制作依赖废料回收与工作台实体操作」——制作不在系统里，在现实里 |
| 副作用 | 道具有效果也有代价：血腥药剂「惊动尸潮」、燃烧瓶「加速目标暴怒」 |
| 系统语气 | 提示带误导性（"你是个良好市民"实为数值嘲讽） |

### 可提炼的结构

1. **图鉴 = 知识型奖励**：不直接给战力，给"知道怎么打"——和文字跑团的判定体系天然契合。
2. **货架分层**：不是"商品锁等级"，而是"整个货架逐层打开"，玩家能预期未来有什么。
3. **技能点 + 属性门槛双前置**：防止"有钱就能点满"。
4. **制作留在现实**：系统给材料/工具，成品要自己动手，工作台/材料/时间都是现实成本。
5. **道具带副作用**：强力道具不是纯增益，这是维持紧张感最便宜的手段。

## 五、三条可以确认的"成熟套路"

1. **单价锚定一只基准怪**。三部里最便宜的可食物/耗材都等于 1 只基准怪（饼干 1 币、棉签 1 分）。玩家不需要换算表就能懂物价。
2. **商城不解决吃饭**，或至少让吃饭很贵。这是"系统不能替代搜集"的唯一可靠实现方式。
3. **成长必须比装备更贵**。属性点 100 只怪、手枪 30 只怪——变强比换枪慢，玩家才会先想"怎么活"。

## 六、明确不采用的东西（避免照搬）

| 参照作品机制 | 为何不用 |
|---|---|
| 新手礼包（币 + 房 + 车 + 刀） | 与"系统不送东西"冲突，会直接抹掉开局压力 |
| 系统签到发币 | 会变成"躺着领钱"，削弱"必须出门"的动机 |
| 商城全品类开放 | 会让玩家跳过"现实搜刮"这一整套玩法 |
| 丧尸图鉴自动鉴定 | 会替玩家完成"认识敌人"的乐趣；本项目把认知留给观察与 NPC 情报 |
| 系统内制作/合成 | 会把现实世界的工具、材料、时间、场地成本全部抹掉 |
| 折算率随系统等级上涨 | 会形成"越后期打低级怪越划算"的反向激励 |
| 满分 10 的小属性面板 | 本项目已定 1—20 区间与 d100 判定，改面板会推翻既有规则 |
| 别墅/移动堡垒类奖励 | 与本项目"据点要自己修"的设定冲突 |

## 七、对本书的三条改造结论

1. **保留"1 只基准怪 = 1 份最便宜食物"的锚**，但本项目基准怪是 10 SP，所以最便宜的一份食物应落在 **8—10 SP**（现有压缩饼干 8 SP ✓）。
2. **饮水保持便宜、但不白给**：本项目不采用 15 倍水价，而是用"自然水必须煮沸/过滤 + 净水片消耗"制造成本。理由：本项目的压力来自**动作与时间**，不是数字。
3. **成长价必须明显高于装备价**：属性点要远贵于一把刀。本项目的处理见 `系统设定/经验与等级.md` 的"换算表"。
