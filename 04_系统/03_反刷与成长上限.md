# 反刷与成长上限

> 这一册存在的理由：如果刷丧尸能变强，这个跑团就变成打怪练级游戏，生存压力和人物关系全部失效。
> 三个系数是**硬算法**，不是"建议"。

## 一、系数 A · 等级差衰减

给每种丧尸一个"威胁等级" ZL：

| 类型 | ZL |
|---|---|
| Z-1 / Z-1b / Z-1c | 1 |
| Z-3 | 2 |
| Z-2 / Z-2b | 3 |
| Z-4 | 4 |
| Z-5b | 5 |
| Z-6 | 5 |
| Z-5 | 6 |

| 主角等级 − ZL | 系数 A |
|---|---|
| ≤ 2 | 1.0 |
| 3—4 | 0.5 |
| 5—7 | 0.25 |
| ≥ 8 | 0.1 |

**含义**：5 级之后打 Z-1 只值 5 SP；10 级之后只值 1 SP。
系统在说一句话：**你已经不需要打这种东西了，去做点别的。**

## 二、系数 B · 区域衰减

按 **300 米网格** 计（城区大约是三条街一块）。

- 每个网格维护一个"清理计数" n，每次在该网格结算一只感染者，n +1。
- 该次结算系数 B = `0.85^(n-1)`，**最低 0.2**。
- 每 6 小时，n 减 1（最低 0）。
- 换网格则重新从 n=0 算（但相邻网格若在同一次行动内，GM 可以合并计为同一片）。

| 同网格当日第几只 | B |
|---|---|
| 1 | 1.00 |
| 2 | 0.85 |
| 3 | 0.72 |
| 4 | 0.61 |
| 5 | 0.52 |
| 6 | 0.44 |
| 7 | 0.37 |
| 8 | 0.32 |
| 9 | 0.27 |
| 10 | 0.23 |
| 11+ | 0.20 |

**含义**：把一个街区反复犁一遍，越犁越不值钱。这符合直觉——也符合现实（东西被搜空了，尸体堆着，风险上升而收益下降）。

## 三、系数 C · 方式

| 方式 | 系数 C |
|---|---|
| 沈砚本人近距离（≤3m）以武器终结 | 1.0 |
| 沈砚本人远程（>3m）射击终结 | 1.0 |
| 陷阱、引爆、制造车祸、坠楼等间接方式 | 0.5 |
| 对已失去行动能力者补刀 | 0.5 |
| 他人造成致命伤，沈砚参与牵制 | 0.3 |
| 他人完成，沈砚仅在场 | 0 |

## 四、算一遍（GM 必须会算）

**场景**：沈砚 5 级，在幸福里 3 号楼（一个网格）连续清理 8 只 Z-1。

每只：`10 SP × A(0.5) × B × C(1.0)`

| 第几只 | B | SP | EXP（5 基数） |
|---|---|---|---|
| 1 | 1.00 | 5 | 2 |
| 2 | 0.85 | 4 | 2 |
| 3 | 0.72 | 3 | 1 |
| 4 | 0.61 | 3 | 1 |
| 5 | 0.52 | 2 | 1 |
| 6 | 0.44 | 2 | 1 |
| 7 | 0.37 | 1 | 0 |
| 8 | 0.32 | 1 | 0 |
| **合计** | | **21 SP** | **8 EXP** |

**而"首次清空一栋楼"的里程碑给 50 SP / 25 EXP。**

结论：**真正赚钱的是"完成一件事"，不是"多砍几刀"。** 这是设计意图，不要绕过。

## 五、软上限（三条）

1. **单日 EXP 软顶**：一天内获得的 EXP 超过 200 之后，超出部分按 50% 计。理由：身体会累，脑子会钝，一天学不到那么多。
2. **里程碑一次性**：同一栋楼的"首次进入""首次清空"只算一次，永远不再给。
3. **禁止补偿性奖励**：不能因为"玩家今天运气不好"就多发 SP。系统不认识运气。

## 六、为什么这样设计（写给 GM 看）

| 如果…… | 会坏掉什么 |
|---|---|
| 刷 Z-1 能一路升到 20 级 | 苏晞会变成累赘，人物关系失去意义；世界沦为刷怪场 |
| 系统能买无限食物 | 搜刮、交易、势力关系全部作废，跑团退化成"打怪—买饭"循环 |
| 高级装备能一枪清场 | 恐怖感消失，Z-5、Z-6 的设计全部浪费 |
| 攒钱能直接买满技能 | 训练时间这个最贵的资源被跳过，成长变成购物 |

**这个世界的成长曲线是这样的**：前 10 天靠运气，第 10—30 天靠关系和位置，30 天之后靠"你能不能让一群人跟着你"。系统只是把前 10 天的死亡率从 70% 降到 50%。
