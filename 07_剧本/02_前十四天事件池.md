# 前十四天事件池（EV-01～EV-30）

> 用法：每天挑 1—2 个"有原因"的事件，不要照顺序放。触发条件不满足就跳过。
> 事件不是任务，是**世界在动**。玩家可以完全不理，后果照常发生。

| 编号 | 触发条件 | 事件 | 后果 |
|---|---|---|---|
| EV-01 | 开局当天 | 秦小雨敲门（见 S3） | 接纳 → 多两张嘴、多一个帮手；拒绝 → 三天后 2 号楼传出味道 |
| EV-02 | 开局当天 | 楼下白色两厢车喇叭停了，车主（已感染）从车里出来 | 院子里多一只 Z-2（新车，快），东墙路线变危险 |
| EV-03 | 玩家第一次下楼 | 3 号楼 401 的老太太隔门问"外面怎么了" | 她不敢开门；给她食物 → 她会在之后提供"楼里谁家有什么" |
| EV-04 | D+7 下午 | 阿豹带三人来"征用"3 号楼 | 交东西 → 记账；拒绝 → 冲突；谈 → 邹文彬会记住你 |
| EV-05 | 玩家在街上待超过 1 小时 | 老陈（NPC-25）被两只 Z-1 追，翻墙摔了 | 救 → 情报 + 关系 +1；不救 → 他会活着记恨你（下次见面抬价） |
| EV-06 | D+8 起 | 自来水彻底停 | 取水成为每天的头等事；高层住户开始下楼，楼道变吵 |
| EV-07 | D+8 起 | 三中开始"清人"（把没用的、有伤的请出去） | 校门口出现几个坐着不走的人；郑淑英会来收 |
| EV-08 | 玩家进三中 | 韩守义的"审"与赵铁的"试" | 过审 → 拿到床位与配给；不过 → 只能在校门口过夜 |
| EV-09 | 苏晞在三中待超过 2 天 | 有人对她说"小姑娘别占床位" | 她会沉默一天；玩家怎么处理，决定她的中期性格 |
| EV-10 | D+9 起 | 白鸽在江北小学缺盐水 | 郑淑英会开口要；给 → 关系 +2；不给 → 她不会记恨，但下次救治会慢 |
| EV-11 | D+9 起 | 苗苗（如在场）退烧后开始咳嗽 | 可能是普通呼吸道感染，也可能是肺炎（需要判定/观察） |
| EV-12 | D+10 起 | 寒潮预警（气温 -3℃） | 燃料价格翻倍；一夜之间有人冻死（GM 决定是谁） |
| EV-13 | D+10 起 | 铁门帮开始收"月供" | 不交 → 阿豹来硬的；交 → 每 7 天一次，越交越多 |
| EV-14 | 玩家去超市 | 老刀请喝茶（真的茶） | 他要谈生意：用你的"手艺"（修东西）换物资 |
| EV-15 | D+11 起 | 东码头出现"过江"生意 | 四人份物资一趟；邱雁会私下告诉你"我爸今天心情不好" |
| EV-16 | D+11 起 | 一名溃兵敲玩家的门，用枪换食物 | 枪可能是坏的；他可能不止一个人；他也可能真的只是饿了 |
| EV-17 | D+12 起 | 体育馆开始发"通行条"（限额） | 拿到 → 可过铁路桥；拿不到 → 只能走渡口或断桥 |
| EV-18 | 玩家靠近二院 | 长庚的车队在做采样 | 被发现 → 被"控制"；躲过 → 可以得到他们的部分装备 |
| EV-19 | D+13 起 | 静默者在地下管网驱离玩家 | 用灯光、弩箭；若玩家带回他们丢失的背包（LOC-02 冷库附近），可建立联系 |
| EV-20 | 任意雨天 | 大雨冲垮了一处简易路障 | 一条新路线打开，也让某片区域的尸群扩散 |
| EV-21 | 玩家受伤未处理 | 伤口开始红肿发烫 | 细菌感染初期；48 小时内用抗生素可逆 |
| EV-22 | 玩家在夜里生火 | 300 米外的窗户后面有人在看 | 第二天有人来"借火"，也可能是来踩点 |
| EV-23 | 苏晞独自外出（首次） | 她记错了路，绕进了死巷 | 玩家必须去找；这会成为她"第一次独自完成一件事"的转折或创伤 |
| EV-24 | 玩家暴露系统（任何形式） | 目击者（苏晞/邻居/据点的人） | 苏晞 → 关系剧变；据点 → 被登记、被看管、被要求"再变一次" |
| EV-25 | D+12 起 | 汽修行的卷帘门被人从外面砸开 | 里面的工具被拿走一部分；后院的陌生面包车还在 |
| EV-26 | 玩家检查老周的办公室 | 抽屉里有半瓶酒、一张写着"二院 地下二层"的便签 | 老周线索 +1 |
| EV-27 | D+13 起 | 江北大桥桥面出现"捡东西的人" | 有人靠桥上的车发财；他们知道哪辆车里有什么 |
| EV-28 | 玩家连续 3 天只吃系统食物 | 苏晞问"这些东西哪来的" | 她的怀疑是合理的：家里没有这么多东西。玩家怎么答，是关系的关键点 |
| EV-29 | 任意时候 | 一只野狗开始跟着玩家（不咬，只要吃的） | 苏晞会给它取名字；它会引来别的狗，也会在夜里叫 |
| EV-30 | D+14 | 体育馆方向传出连续枪声（持续 20 分钟） | 之后一周，体育馆的配给减半，逃出来的人带来互相矛盾的传言 |

## 事件配速建议

| 天 | 建议配 | 目的 |
|---|---|---|
| D+7 | EV-01、EV-02、EV-04 | 建立压力与人物 |
| D+8 | EV-06、EV-08（若去三中）、EV-07 | 让"资源"变成"制度" |
| D+9 | EV-10、EV-11、EV-05 | 救治与道德选择 |
| D+10 | EV-12（寒潮）、EV-13 | 冬天提前敲门 |
| D+11 | EV-15、EV-16 | 外部世界（过江、溃兵） |
| D+12 | EV-17、EV-25、EV-28 | 通行、线索、系统秘密 |
| D+13 | EV-19、EV-26、EV-27 | 地下、师父、桥 |
| D+14 | EV-30、EV-18（若靠近二院） | 大势力登场，进入第二幕 |

**同一天不要放两条"重大"事件。** 一条重大的 + 一条日常的，节奏最好。
