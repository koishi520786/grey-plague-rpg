# 现实经济与物资流通

> 这一册管**系统以外**的一切交易。系统货币 SP 的规则在 `交易系统/末日生存交易手册.md`，两者不能互相兑换。

## 一、现金还剩多少用

| 阶段 | 100 元能买到 | 说明 |
|---|---|---|
| D0 之前 | 三天伙食 | 正常世界 |
| D+7（开局） | 一瓶 500ml 水，或者没人要 | 八成商户不收；收的人多半出于习惯或同情 |
| D+14 | 没人要 | 只剩"心理价值"：有人仍然把钱包塞在内袋里 |
| D+30 | 可以当引火纸 | — |

**仍然收现金的人**：老一辈（觉得"钱总是钱"）、有店铺仍在营业的个体户、需要记账的"官方"据点（体育馆收现金，但只抵扣极小额度、且要登记）。

**规则**：现金不能兑换 SP，SP 也不能兑换现金。系统对现金没有任何反应。

## 三、物资来源

| 来源 | 常见 | 风险 | 说明 |
|---|---|---|---|
| 自己家/邻居家 | 食品、衣物、药 | 低 | 早期主要来源，一周内被搜空 |
| 临街小店 | 烟酒、饮料、日用品 | 中 | 卷帘门多，出声大 |
| 超市/批发部 | 成箱食品、水 | 高 | 有主，或有人守 |
| 仓库/物流园 | 建材、五金、轮胎 | 中 | 需要车和搬运时间 |
| 尸体身上 | 现金、钥匙、手机、少量药 | 中 | 有感染风险；心理压力 |
| 车里 | 油、行李、工具 | 中高 | 车门锁着，报警器会响 |
| 军方配给 | 压缩饼干、净水片 | 低 | 要用劳动或通行条换 |
| 黑市 | 几乎任何东西 | 中 | 价格是基准表的两倍起 |
| 系统商店 | 见 `交易系统/` | 无 | 只有沈砚能用 |

## 四、价格浮动规则

现实世界的价格会变，但要**有理由地变**，而且要 GM 记录。

| 事件 | 影响 |
|---|---|
| 某个据点被攻破 | 该据点周边物资紧 → 价格上涨 30—60%，持续 3—7 天 |
| 军方车队进城 | 药品、弹药短期流入 → 黑市降价 20% |
| 寒潮 | 燃料、保暖衣物、热食涨价 100% 以上 |
| 一场大规模交火 | 弹药被抢空，枪反而降价（有枪没弹） |
| 有人传出"南边有安置点" | 地图、燃料、车、渡船票全线涨价 |

**记录要求**：每次成交把日期、物品、数量、成交价、交易对象记进台账的"交易"栏。价格不能随剧情临时改——要改先改这一册。

## 五、常见交易场景

**三中（F-01）**：内部用"工分"，1 小时劳动 = 2 工分 = 一份配给。对外只换物资，不换现金。他们最缺柴油和药。

**超市帮（F-03）**：明码标价，比基准表贵 50—100%，收物资也收"消息"。可以赊账，利息是一天 10%，还不上就换别的还。

**白鸽（F-04）**：治病不收钱。但会在你走的时候说一句"下次带点盐水来"。这句话不是请求。

**邱家船帮（F-07）**：过江费四人份物资。不认 SP。会临时加价（"今天风大"）。

**柳树村（LOC-24）**：只换不卖。粮、菜、柴都能换，但他们只收工业品（电池、盐、铁器、药）和"外面到底怎么了"的完整叙述。

**拾荒者**：情报贩子。一条可靠情报换半包烟；假情报也收钱——所以要判定对方是否在骗你（感知 + 交涉）。

## 六、稀缺度速查（D+7 基准）

| 等级 | 品类 |
|---|---|
| **极缺** | 抗生素、胰岛素、血浆、柴油、防寒衣、鞋、女性卫生用品 |
| **缺** | 电池、燃料、盐、糖、奶粉、婴儿用品、打火机、卫生纸 |
| **一般** | 罐头、大米、瓶装水（居民楼里还有）、绳索、胶带 |
| **充足** | 家具、衣服（不一定合身）、书籍、装饰品、办公用品 |
| **过剩（无价值）** | 现金、股票凭证、名贵包表（换不到一顿饭，但有人愿意为它付出——这是人性，不是价格） |
